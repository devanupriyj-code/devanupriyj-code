#### 🚚 Case File #001: [CityScale](https://github.com/devanupriyj-code/cityscale)
> **Last-Mile Logistics Optimization Platform**

A full-stack, enterprise-grade last-mile logistics optimization engine engineered for real-time fleet telemetry, algorithmic route resolution, and high-concurrency dispatch simulations.

- 🚀 **1,000 Simulated Vehicles**: Concurrently tracked in real-time under high simulation load.
- ⚡ **14 ms p95 Tick Latency**: Sustained sub-15ms deterministic physics and routing evaluation loops.
- 🛠️ **124 REST API Handlers**: Complete microservice controller suite managing dispatch lifecycles, route tracking, and vehicle states.
- 🗄️ **15 PostgreSQL Tables**: Structured persistence managed through Spring Data JPA with Flyway database migration versioning.
- 📡 **STOMP WebSockets**: Full-duplex real-time fleet telematics streaming directly to connected dispatch monitors.
- 🧩 **Algorithmic Arsenal**: Dijkstra, A*, KD-Tree nearest neighbors, K-Means++ spatial clustering, Greedy Dispatch, TSP, and 2-opt heuristics.
- 📈 **35% Efficiency Gain**: A* heuristic explored approximately **35% fewer nodes** than standard Dijkstra search.

#### 🔎 Case File #002: [Website RAG Platform](https://github.com/devanupriyj-code/website-rag-platform)
> **AI-Powered Website Intelligence and Search**

An intelligent Retrieval-Augmented Generation (RAG) system that crawls raw websites, indexes unstructured textual corpora, and yields sub-second, context-grounded AI responses.

  <img src="https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white" />

- 🕷️ **Multi-Threaded Web Crawler**: Harvested and indexed 100+ webpages using thread synchronization primitives, safe queues, and resilient HTTP networking.
- 🔍 **Dual-Stage Hybrid Search**: Combines an inverted-index TF-IDF lexical engine with 384-dimensional dense vector embeddings via Sentence Transformers.
- ⚡ **Sub-Second AI Generation**: Integrated Groq LLM API for low-latency reasoning over retrieved context chunks.
- 📉 **42% Search Latency Reduction**: Slashed round-trip retrieval latency from 1.2s down to 0.7s through inverted-index token caching.
- 🐳 **Lightweight Architecture**: SQLite relational storage optimized for fast token indexing and Docker deployment.
